# AI-Based Skill Gap Analysis and Career Readiness Prediction

## Project Overview

The AI-Based Skill Gap Analysis and Career Readiness Prediction project aims to analyze students' skills, identify skill gaps, and assess their career readiness. It helps students understand their strengths and weaknesses and identify the skills they need to improve for their desired careers.

The project is developed using R and an interactive Shiny dashboard to present data analysis results through visualizations and summaries.

## Objectives

* Analyze student data to understand skill levels.
* Identify skill gaps and areas for improvement.
* Group students based on their skill profiles.
* Visualize student data using charts and graphs.
* Help students understand their career readiness.
* Support career planning through data-driven insights.

## Technologies Used

* **Programming Language:** R
* **Dashboard Framework:** Shiny
* **Data Visualization:** ggplot2
* **Clustering:** K-Means
* **Dimensionality Reduction:** Principal Component Analysis (PCA)
* **Data Processing:** R data manipulation functions

## Project Features

* Interactive dashboard for exploring student data.
* Data cleaning and preprocessing.
* Skill gap analysis.
* Student grouping based on skill profiles.
* Graphical representation of analysis results.
* Summary of findings to support career planning.

## Project Files

* `app.R` – R Shiny application code.

## Installation Requirements

Install R and RStudio on your computer.

Install the required R packages by running the following command in the R console:

```r
install.packages(c("shiny", "ggplot2", "cluster"))
```

Install any additional packages required by your `app.R` code.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in RStudio.
3. Ensure that the dataset is in the correct folder.
4. Open `app.R`.
5. Run the following command in the R console:

```r
shiny::runApp()
```

6. The Shiny dashboard will open in your default web browser.
